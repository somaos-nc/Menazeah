# Menazeah Tutorial

Welcome to Menazeah, the conductor of your collaborative AI coding journey.

## Steps to Success

1. **Launch Menazeah**: Open the application. You will see two terminal windows.
2. **Login**: Use the login prompt to authenticate with your account and GitHub.
3. **Initialize Project**:
   - Create a new project folder.
   - Link it to a GitHub repository using `gh repo create`.
4. **Invite Teammates**: Use the search panel to find teammates by email or name and add them to your project.
5. **Start CoCoding**: Your Gemini CLI is ready on the right terminal. The left terminal will show a live feed of the orchestration and team communication.
6. **Continuous Sync**: Menazeah handles the background merging and `rsync` synchronization.

## Tips

- Keep an eye on the left terminal for merge status and AI insights.
- Use RTL languages naturally; Menazeah supports them.
- Follow the WTTITRTL kata for all code changes.
